# C5 — Seuils de réassort

Rempli avec des données fictives pour l'exemple.

- Couverture cible, au-delà du délai de livraison : **30 jours**
- Seuil de surstock : **plus de 90 jours** de couverture
- Références à ne jamais laisser en rupture : **SE-010** (sérum vitamine C, meilleure vente), **PR-060** (solaire SPF50, saisonnier)
